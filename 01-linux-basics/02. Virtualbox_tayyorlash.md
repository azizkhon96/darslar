# Virtualboxni labaratoriya uchun tayyorlash

### Asosiy atamalar

**Virtualizatsiya** — bu bitta fizik server (Hardware) resurslarini (CPU, RAM, Disk, Network) maxsus dasturiy ta'minot yordamida bir nechta mantiqiy  qismlarga bo'lib berish texnologiyasidir.

**Virtual Mashina (VM)** — bu fizik kompyuterning ichida dasturiy yo'l bilan yaratilgan, o'zining "virtual" apparat ta'minotiga (vCPU, vRAM, vHDD) ega bo'lgan to'liq mustaqil operatsion tizimdir.

**Gipervisor (Hypervisor)** — bu bitta jismoniy kompyuterda bir nechta virtual kompyuterlarni (VM) ishga tushirish va boshqarish uchun xizmat qiladigan dasturiy ta'minot. Virtualbox aynan shu gipervisor dasturlaridan biri hisoblanadi. 

### Virtualbox'da VM yaratish va sozlash

Virtualbox dasturini quyidagi link orqali ko'chirib olib o'rnatishingiz mumkin: https://www.virtualbox.org/wiki/Downloads

O'rnatilgandan keyin VM yaratish quyidagicha, virtualboxni ochasiz va asosiy oynada **New(Новый)** tugmasini bosasiz , VM oynasi chiqadi , uni ichidan kerakli parameterlarni to'ldirasiz. 

ISO image qaysi OS o'rnatishingizga qarab yuklab olasiz, masalan linuxni debian turini o'rnatmoqchi bolsak quyidagi link orqali yuklash olishingiz mumkin : https://www.debian.org/distrib/. Bu yerdan `64-bit PC netinst iso` deb nomlangan versiyani olish kerak. 

VM yaratilgandan keyin uni sozlamalar (Settings) bo'limiga kirib tarmoq sozlamasini sozlaymiz. U yerda mavjud tarmoq turlaridan 3 ta asosiysini ko'rib chiqamiz:

- NAT - VM internetga chiqadi , VM ichiga SSH orqali kirish uchun qo'shimcha sozlash kerak.
- Host Only - VM internetga chiqolmaydi, VM ichiga SSH orqali kirish mumkin.
- Bridged - VM internetga chiqadi, VM ichiga SSH orqali kirish mumkin.
